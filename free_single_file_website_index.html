How to deploy for free

  1. Create a GitHub repository, add index.html, and enable GitHub Pages in repo settings.
  2. Or drag-and-drop the file to Netlify's dashboard or connect your GitHub repo to Netlify/Vercel/Cloudflare Pages for automatic deploys.
  3. Optionally add a custom domain and HTTPS (most providers offer free TLS).

See provider docs for step-by-step guides (GitHub Pages, Netlify, Vercel, Cloudflare).
